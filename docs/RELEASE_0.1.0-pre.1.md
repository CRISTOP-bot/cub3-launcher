# CUB3 Launcher 0.1.0-pre.1

Primera compilación pública para Linux de 64 bits.

## Plataforma disponible

- Debian y Ubuntu x86_64: paquete `cub3-launcher-0.1.0-x86_64.deb`.
- Windows y macOS: próximamente.

Instala el paquete con `sudo apt install ./cub3-launcher-0.1.0-x86_64.deb`.
Se requiere Java compatible con la versión de Minecraft elegida; Minecraft
26.3 requiere Java 25.

El SHA-256 del paquete se adjunta como `SHA256SUMS` en los archivos de esta
release.
