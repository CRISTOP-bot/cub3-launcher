Información para quienes descargan o usan CUB3 Launcher.

Última actualización: 17 de noviembre de 2026
Importante: CUB3 está en desarrollo y se ofrece sin garantía. Esta página explica las prácticas actuales del proyecto; no sustituye los términos de Microsoft, Mojang Studios, Ely.by ni asesoría legal.

1. Uso del launcher

  • Usa CUB3 solo con cuentas y servicios a los que tengas derecho de acceso, respetando sus condiciones y las leyes aplicables.
  • No uses el launcher para evadir controles de acceso, distribuir contenido sin autorización, atacar servicios ni perjudicar a otras personas.
  • CUB3 es un proyecto independiente, no oficial y no afiliado, respaldado ni aprobado por Mojang Studios o Microsoft. Minecraft y sus marcas pertenecen a sus titulares.
  • El software puede cambiar, contener errores o dejar de funcionar. Haz copias de seguridad de tus mundos, perfiles y configuraciones antes de actualizar o probar builds de desarrollo.

2. Datos que guarda CUB3

Según la implementación actual, CUB3 guarda localmente preferencias, base de datos, instalaciones, archivos descargados y registros en las carpetas de datos de la aplicación; la caché y miniaturas van en la carpeta de caché del usuario. La ubicación depende del sistema operativo y de Qt.

Los tokens de sesión se guardan mediante el llavero de credenciales del sistema. CUB3 no pretende guardar contraseñas y no usa una base de datos ni archivos de texto como respaldo inseguro de tokens. Si el llavero no está disponible, el guardado puede fallar y el launcher lo informa.

La app consulta servicios externos para iniciar o validar sesiones, obtener el manifiesto y archivos de Minecraft y mostrar noticias. Según la función que uses, esos servicios pueden recibir solicitudes de red y los datos necesarios para atenderlas; sus propios avisos y políticas rigen el tratamiento que hagan.

El proyecto no ofrece actualmente una cuenta web de CUB3. Esta página describe las funciones del código público disponible; si se incorporan nuevas integraciones, la política se actualizará. La web pública carga tipografías desde Google Fonts y se aloja en GitHub Pages; esos proveedores pueden recibir datos técnicos de conexión al cargar la página y aplican sus propias políticas.

3. Control y seguridad

  • Para cerrar sesión, usa la opción correspondiente dentro del launcher; CUB3 intenta retirar las credenciales guardadas del llavero.
  • Puedes borrar preferencias, caché, registros, mundos o instalaciones desde el almacenamiento local del sistema. Haz primero una copia si quieres conservarlos.
  • No compartas contraseñas, códigos de acceso ni tokens con el equipo del proyecto. Para solicitar ayuda técnica, elimina esos datos de cualquier captura o registro antes de publicarlo.
  • Protege tu cuenta del sistema operativo y mantén actualizados tanto CUB3 como el sistema y sus servicios de credenciales.

4. Cambios y contacto

Esta política puede cambiar conforme cambien la app y sus integraciones. La versión vigente se publicará en esta página. Para reportar un problema o proponer una corrección, usa el rastreador público de GitHub; no publiques secretos ni información personal.

Esta política describe el proyecto tal como está implementado y publicado hoy; no representa una promesa de seguridad absoluta ni una garantía de disponibilidad o compatibilidad.
