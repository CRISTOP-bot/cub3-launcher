# Instrucciones para agentes y colaboradores

- **Toda modificación del proyecto se trabaja y se publica en `dev`.** Esto
  incluye código, documentación, recursos, configuración y sitio web.
- Antes de editar, verifica la rama actual y cambia a `dev`. No escribas,
  confirmes ni publiques cambios en `main` ni crees ramas de trabajo aparte.
- Si el árbol de trabajo tiene cambios, consérvalos al cambiar de rama; nunca
  los descartes para cumplir esta regla.
- Mantén `main` como rama estable. Las propuestas de integración hacia `main`
  se reservan para una promoción de versión decidida por el mantenedor.
- Consulta `CONTRIBUTING.md` para compilar, validar cambios y preparar commits.
- No afirmes que se ejecutaron pruebas si no se ejecutaron. Documenta con
  claridad limitaciones y funciones todavía no implementadas.
- No incluyas tokens, credenciales, archivos `.env` ni datos personales.
